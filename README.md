# app_store_search

Web tool that searches Google Play or the Apple App Store and downloads the results as CSV.

- Originally hosted at http://still-dusk-89361.herokuapp.com (Heroku, recovered March 2023).
- Run locally: `npm install && npm start`, then open http://localhost:5000
- Hosting: any Node host works; the server listens on `$PORT` (default 5000).
